Build me a complete, single-file web-based Habit & Study Tracker called "FocusFlow". It must be a single HTML file with embedded CSS and JavaScript, fully functional with localStorage persistence (no backend needed). The design should be premium, minimal, and aesthetic.

## CORE FEATURES

### 1. Dashboard Overview (Top Section)
- Show current date, day, and live clock (synced with browser time).
- Display key stats in cards:
  - Today's Total Study Hours
  - Current Streak (consecutive days with at least 1 study session logged)
  - Weekly Goal Progress (e.g., "12/20 hrs")
  - Completion Rate % for the current month
- A motivational quote that changes daily.

### 2. Study Session Logger (Main Input)
A clean form to log each session:
- **Subject**: Dropdown/Input with preset options (Math, Science, Programming, Design, Language, Reading, Writing, Other) + ability to add custom subjects.
- **Date**: Defaults to today, but editable via a date picker.
- **Time Started & Time Ended** (or just Duration in hours/minutes).
- **Hours Studied**: Auto-calculated from time range, or manual entry.
- **Goal/Topic**: What specific goal or chapter was targeted.
- **Remarks/Notes**: A textarea for reflections, difficulty, or key takeaways.
- **Mood/Productivity Rating**: 1-5 star rating (optional but stored).
- **"Log Session" Button**: Saves entry and updates all stats instantly.

### 3. Calendar View
- A full monthly calendar that syncs with the browser's date.
- Days with logged sessions should be highlighted:
  - Color intensity based on total hours studied that day (darker/more saturated = more hours).
  - Clicking a day opens a popup/modal showing all sessions for that date.
- Navigation arrows to switch months.
- Today should be clearly marked.
- Streak indicators: small fire icons on days that continued a streak.

### 4. Habit/Subject Grid (Daily Tracker)
- A scrollable grid similar to GitHub contributions or the uploaded reference image.
- Rows = Subjects/Habits.
- Columns = Days of the current month (1-31).
- Each cell is a checkbox or clickable square:
  - Empty = no study
  - Filled green = studied that subject on that day
  - Hovering shows hours studied and remarks tooltip.
- Toggle between "Month View" and "Week View".

### 5. Goals & Remarks Section
- **Goals**: A dedicated area to set weekly/monthly study goals per subject. Track progress with progress bars.
- **Remarks History**: A searchable, filterable log of all past remarks/notes. Filter by subject, date range, or rating.

### 6. Data Management
- **Export**: Download all data as JSON or CSV.
- **Import**: Upload JSON/CSV to restore data.
- **localStorage**: All data persists across browser sessions. Include a "Clear All Data" button with confirmation.

## DESIGN SYSTEM

### Dark Mode (Default)
- Background: Deep navy blue (#0B1120, #0F172A gradients).
- Surface/Cards: Slightly lighter navy (#1E293B).
- Primary Accent: Aesthetic grass green (#4ADE80, #22C55E).
- Text: Off-white (#F8FAFC) for headings, muted slate (#94A3B8) for secondary text.
- Borders: Subtle dark borders (#334155).
- Success/Checkmarks: Bright grass green with soft glow.
- Hover effects: Smooth scale and brightness transitions.

### Light Mode (Toggle Switch in Header)
- Background: Off-white / warm white (#FAFAF9, #F5F5F4).
- Surface/Cards: Pure white (#FFFFFF) with soft shadow.
- Primary Accent: Rich grass green (#16A34A, #15803D).
- Text: Dark charcoal (#1C1917) for headings, warm gray (#78716C) for secondary.
- Borders: Light gray (#E7E5E4).
- Toggle: A sun/moon icon in the top-right corner. Preference saved to localStorage.

### Typography & UI
- Use Inter or Geist font (Google Fonts).
- Rounded corners (rounded-xl, rounded-2xl).
- Smooth animations: fade-ins, slide-ups, number counting animations for stats.
- Glassmorphism subtle effects on cards (optional but nice).
- Fully responsive: works on mobile, tablet, and desktop.

## TECHNICAL REQUIREMENTS
- Single HTML file only. All CSS in `<style>`, all JS in `<script>`.
- Use vanilla JavaScript (no frameworks).
- Use Tailwind CSS via CDN for styling utility.
- localStorage keys: `focusflow_sessions`, `focusflow_goals`, `focusflow_settings`.
- Calendar must use native JS Date objects, no external calendar libraries.
