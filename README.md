# FocusFlow

FocusFlow is an aesthetic offline-first study habit tracker designed to help you stay consistent with your studies. It runs entirely in your browser, so there is no installation, no account creation, and no internet connection required after the first visit.

## Features

- **Study Session Logging** - Record sessions with subjects, duration, topics, and remarks
- **Goals Management** - Set and track weekly study goals
- **Calendar View** - View all study sessions in an interactive calendar
- **Habit Grid and Streaks** - Build consistency with streak tracking
- **Pomodoro Timer** - Stay focused using the built-in timer
- **Task Management** - Organize tasks with deadlines and completion status
- **Bookmarks** - Save important study resources and links
- **Search** - Quickly search through study sessions and data
- **Statistics** - View insights into study habits and progress
- **Customization** - Personalize subjects, tags, and settings
- **Import and Export** - Create backups and restore data

## 🌐 Use the App

Bookmark and enjoy FocusFlow at: **https://focusflow7.netlify.app/**

*Note: All data is stored locally in your browser. Remember to export your data before clearing browser cache.*
